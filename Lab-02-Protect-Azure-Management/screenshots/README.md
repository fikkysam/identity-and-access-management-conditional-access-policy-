# Lab 02 — Screenshot Evidence

Store sanitized screenshots for **Protect Azure Management** in this folder.

## Recommended evidence

1. Policy details showing the policy name, Report-only state, included user, excluded identity, target resource, and MFA requirement.
2. Target resource picker showing **Azure Resource Manager** selected.
3. Interactive sign-in event showing the test user, Azure Portal application, Azure Resource Manager resource, and successful sign-in.
4. Report-only tab showing `Protect-Azure-Management`, the MFA grant control, and its evaluation result.

## Redaction requirements

Before committing screenshots to this public repository, hide or crop:
- User principal names and personal names where not necessary.
- Tenant or directory identifiers.
- IP addresses.
- Request IDs and correlation IDs.
- Any tokens, passwords, temporary codes, or other secrets.

Do not upload screenshots containing credentials or authentication secrets.

Screenshots from the lab session should be uploaded here through GitHub's web interface. This evidence folder currently contains this checklist until the image files are added.
